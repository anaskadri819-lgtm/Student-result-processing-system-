# Student Result Processing System – READ

The Student Result Processing System is a fully SQL-based mini‑project built using MySQL. It is designed to manage student academic data such as courses, grades, semesters, GPA, and CGPA. This repository includes complete schema, sample dataset, triggers, GPA logic, ranking queries, and export utilities.

This project is suitable for:

 Mini projects (BCA, BSc CS, Diploma, B.Tech)
 Database Management System (DBMS) assignments
 College examination result automation


Objectives

* Store and manage student information, courses, semesters, and grades.
* Automatically map marks → grade → grade points.
* Calculate semester GPA and cumulative CGPA using triggers.
* Generate grade reports and pass/fail statistics.
* Produce semester-wise rank lists using window functions.
* Export semester summaries for reporting.



# Technologies Used

* *MySQL 8+* (required for window functions)
* SQL (DDL, DML, triggers, stored proced)
